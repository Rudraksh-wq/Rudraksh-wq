## Projects
 
**[USMA – Unified Scholarship Mobile Application](https://github.com/Rudraksh-wq/USMA)**
A single-window Flutter app for Ministry of Tribal Affairs scholarships (SIH 2026, PS SIH26238). Includes an eligibility checker, application and DBT disbursement tracking, a document vault, a multilingual chatbot, and offline support. Built with Flutter, Riverpod, Firebase and Hive.
 
**[SatQuery AI](https://github.com/Rudraksh-wq/SatQuery_AI_SIH2026)**
An interactive vision-language assistant for satellite imagery analysis through text queries (SIH 2026, PS SIH26167, team Vibe_coders). Combines a fine-tuned PaliGemma model with GeoTIFF and SAR processing, change detection, and a Streamlit interface. Forked from [krishpr07/SatQuery-AI](https://github.com/krishpr07/SatQuery-AI).
 
**[Attensia – Attention Span Decay Analyzer](https://github.com/Rudraksh-wq/Attensia-Attention-Span-Decay-Analyzer)**
Analyzes YouTube watch history (Google Takeout) to show attention span trends, completion rates, and short-form vs long-form viewing. Built with Python, Pandas, Plotly and Streamlit.
 
**[Password Generator](https://github.com/Rudraksh-wq/password-generator)**
A command-line tool that generates random passwords with a custom length and character mix. Built in Python.
 
**[git-journey](https://github.com/Rudraksh-wq/git-journey)**
A practice repository from learning Git and version control.
